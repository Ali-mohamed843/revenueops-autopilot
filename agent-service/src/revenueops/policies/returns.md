# Returns and refunds

- **RET-1** Answer every return request within 48 hours.
- **RET-2** Refunds over 300 EGP always need a person.
- **RET-3** Refund only after the item is received back, except items damaged on arrival with photo evidence, which a person reviews.
- **RET-4** The return window is 14 days from delivery.
